# Lecture Transcriber（講義動画リアルタイム文字起こしアプリ）

PCで再生している講義動画（YouTube、Zoom、大学LMS、録画ファイルなど）の音声をリアルタイムでキャプチャし、ローカルAI（`faster-whisper`）で無料・オフライン文字起こしするデスクトップアプリです。**Windows版・macOS版の両方に対応**しています。

## 主な機能

- **PC内部音声（システム音声）の直接文字起こし**:
  - **Windows**: 追加ドライバ不要で WASAPI ループバック音声をそのまま取得可能
  - **macOS**: BlackHole 2ch 等の仮想オーディオデバイスまたはマイクから取得可能
- **リアルタイム字幕表示**:
  - 話している途中の「暫定テキスト」と、文の区切りで確定する「タイムスタンプ付きログ」を同時表示
  - **フローティング字幕オーバーレイ**: 講義動画の上に常に最前面・半透明で字幕を重ねて表示可能（ドラッグ移動・サイズ変更・文字サイズ調整対応）
- **高速・高精度なローカルAI**:
  - NVIDIA GPU（CUDA）を自動検出し、超高速で文字起こし（非GPU環境・MacではCPU最適化モードで動作）
  - 日本語・英語・自動検出、モデルサイズ（`tiny` 〜 `large-v3-turbo`）を切り替え可能
- **講義ノートの保存・検索**:
  - リアルタイムキーワード検索、ワンクリック全文コピー
  - `.txt`（タイムスタンプ付き）、`.md`（Markdown講義ノート）、`.srt`（動画字幕ファイル）形式で保存可能

## 起動方法

### Windows版

1. `run_windows.bat` をダブルクリックして起動します（初回のみ仮想環境と必要パッケージを自動セットアップします）。
2. アプリが開いたら、音声ソースで **`[システム音声 ★推奨]`** が選ばれていることを確認します。
3. **`▶ 文字起こし開始`** をクリックして講義動画を再生してください。

> **※ 初回起動時のモデルダウンロードについて**  
> 初めて「▶ 文字起こし開始」を押したとき、選択したAIモデル（例: `small` 約500MB）が自動ダウンロードされます。2回目以降はオフラインですぐに開始できます。

### macOS版

1. ターミナルで以下を実行し、実行権限を付与して起動します：
   ```bash
   chmod +x run_mac.sh
   ./run_mac.sh
   ```
2. **MacでPC内部音声（講義動画の音）を直接文字起こしする場合の推奨設定**:
   - 無料の仮想オーディオドライバ **BlackHole 2ch**（`brew install blackhole-2ch`）をインストールします。
   - Macの「Audio MIDI設定」を開き、左下の「＋」→「複数出力装置を作成」から、普段使っているスピーカー（またはイヤホン）と `BlackHole 2ch` の両方にチェックを入れます。
   - Macのシステムサウンド出力をその「複数出力装置」に切り替え、アプリ側の音声ソースで **`[仮想音声/システム音声] BlackHole 2ch`** を選択すると、講義を聞きながらリアルタイム文字起こしできます。

## スタンドアロンアプリ（.exe / .app / .dmg）のビルド方法

- **Windows (.exe)**:
  `scripts\build_windows.bat` を実行すると、`dist\LectureTranscriber\LectureTranscriber.exe` が生成されます。
- **macOS (.app / .dmg)**:
  Mac上で `chmod +x scripts/build_mac.sh && ./scripts/build_mac.sh` を実行すると、`dist/LectureTranscriber.app` および `dist/LectureTranscriber-macOS.dmg` が生成されます。
- **GitHub Actions 自動ビルド**:
  `.github/workflows/build.yml` を同梱しているため、GitHubリポジトリにプッシュするだけで Windows版・macOS版の両方をクラウド上で自動ビルドできます。
